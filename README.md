# SkincareBD_Internship_AuthenticFour

Frontend-only skincare e-commerce demo ("skincare bd") built for the Authentic Four internship, Project Track. Plain HTML, CSS and JavaScript. No framework, backend or build step.

## Features
- Automatic banner slider that changes every 5 seconds (arrows, dots, pauses on hover)
- Separate **New Arrival**, **Best Selling** and **Sale** sections, plus **Shop All** with 20 products
- Brands: Simple, The Ordinary, Garnier, Supergoop!, Numbuzin, Innsaei, Pacifica, Drunk Elephant, Glow Recipe, Mamaearth and more
- Working **Add to Bag**, cart quantity (+ / -), remove item and **subtotal**
- Working **favourites** and live **search** by name, brand or category
- Category filters: Sunscreen, Serum, Toner, Cleanser, Moisturizer, Treatment
- Cart and favourites saved in the browser (localStorage)
- Responsive layout for desktop, tablet and mobile

## How to run
Open `index.html` in any browser (or use VS Code Live Server).

## Files
- `index.html` page structure
- `styles.css` styling
- `app.js` product data, cart, favourites, search, slider
- `images/products/` product photos (see below)
- `IMAGE_CHECKLIST.md` exact file name for every product photo

## Product photos
All 20 products use real product photos from `images/products/`. File names are listed in `IMAGE_CHECKLIST.md`. If a photo is missing, a simple illustration shows instead.

## Notes
- Demo only: checkout and payment are not connected.
- Prices are illustrative sample values, not live inventory.
- Brand names belong to their owners and are used for learning purposes only.
