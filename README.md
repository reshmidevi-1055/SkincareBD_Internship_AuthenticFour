# Skincare BD – Online Skincare Store (Front-End)

A responsive front-end skincare shopping website ("skincare bd"), built with HTML, CSS and JavaScript. It has a banner slider, product sections, a working shopping bag, favourites, search and category filters, all running in the browser.


## Features
- **Home banner slider:** changes automatically every 5 seconds, with arrows and dots.
- **Product sections:** New Arrival, Best Selling, Sale and Everyday Favourites (products with real photos, prices and discount badges).
- **Shopping bag:** Add to Bag, change quantity (+ / -), remove item and live subtotal.
- **Favourites:** save and remove products with the heart button.
- **Search:** find products by name, brand or category.
- **Category filters:** Cleanser, Serum, Moisturizer, Sunscreen and Treatment.
- **Saved in the browser:** bag and favourites stay after refresh (localStorage).
- **Responsive design:** works on desktop, tablet and mobile.

## Technologies Used
- HTML5
- CSS3
- JavaScript (vanilla)
- Browser localStorage

## How to Run the Project
1. Download or clone this repository.
2. Open the folder and double-click `index.html`, or right-click it in Visual Studio Code and choose **Open with Live Server**.
3. Browse the products, add items to the bag, save favourites and try the search and filters.

No installation is needed.
